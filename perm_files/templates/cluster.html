How to read this page — click to collapse

Work isn't moving

  • Pending reasons names the blocker directly.
  • Capability row with waiting>0, workers=0 can never run — start a matching worker.
  • Parked jobs left the queue and wait for a capability; they cost nothing while parked.
  • Dead-letter above zero means jobs gave up entirely.

Work is slow

  • Queue wait p99 high, execution normal → the scheduler is the bottleneck, not your scripts.
  • Dispatch loop spiking → one slow placement stalls the whole cluster; the loop is single-threaded.
  • Store write latency matters here too — two writes sit inside that loop.
  • Use the latency budget table to see which layer dominates.

A node misbehaves

  • Heartbeat RTT climbing on one line = that link is degrading before it is declared dead.
  • Solid line = permanent node, dashed = ephemeral.
  • Click a node in Topology for slots, services, what's running now and RTT history.

Queue composition

  • Blocked growing is normal in a deep DAG — those jobs wait on parents.
  • Ready growing is not — work is eligible and nothing is dispatching it.
  • Delayed is the DelayQueue; those cost no CPU while waiting.

Topology

  • Solid outline = permanent node you started.
  • Dashed = ephemeral, spawned by the scaler, reclaimed after 45s idle.
  • The ring shows occupied slots; a full red ring means saturated.

Store & retention

  • Dropped writes is the real outage signal — the store fails open, so errors stay at 0.
  • State drift means the store lists nodes the Master no longer has.
  • Series are in-memory rings: pick a window with the history selector. All of it is lost on Master restart.
